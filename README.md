# gac-models

Salinan model Whisper large-v3-turbo (faster-whisper / CTranslate2) dari [mobiuslabsgmbh/faster-whisper-large-v3-turbo](https://huggingface.co/mobiuslabsgmbh/faster-whisper-large-v3-turbo), lesen MIT.
